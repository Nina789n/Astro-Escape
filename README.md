# 🚀 Astro Escape

## About the Project
Astro Escape is a 2D game developed using JavaScript and HTML5, featuring an interactive gaming experience.

## Technologies Used
- JavaScript
- HTML5
- CSS3

## Features
- 2D game environment
- Interactive gameplay
- Player movement and controls
- Space-themed experience

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
